# BigArm DH 参数与 URDF 坐标系

来源：`Simulation/【装配体】单臂/robot.urdf`。约定 `q=0` 为 CAD 装配位姿，长度单位 m、角度单位 deg，采用改进 DH（Craig）。

$${}^{i-1}T_i = R_x(\alpha_{i-1})\,D_x(a_{i-1})\,R_z(\theta_i)\,D_z(d_i)$$

## 1. base -> frame 1（安装变换）

| 项目 | 数值 |
|---|---|
| xyz [m] | (0.000558840, -0.020852994, 0.038000000) |
| rpy [deg] | (90.0000, -90.0000, 0.0000) |

## 2. DH 参数

| i | alpha_(i-1) [deg] | a_(i-1) [m] | d_i [m] | theta_i | theta 偏置 [deg] |
|---:|---:|---:|---:|---|---:|
| 2 | 0 | 0.410500 | -0.089700 | q_2 | -72.5122 |
| 3 | +90 | 0 | 0 | q_3 | -90.0000 |
| 4 | +90 | 0 | +0.188000 | q_4 | -90.0000 |
| 5 | +90 | 0 | -0.002500 | q_5 | +170.7537 |
| 6 | +90 | 0 | +0.207000 | q_6 | +10.6950 |
| 7 | +90 | 0 | 0 | q_7 | -148.8586 |
| 8 | +90 | 0 | 0 | q_8 | 0.0000 |

`q_i` 是 URDF 关节值，零位保持 CAD 装配姿态；DH 角满足 `theta_i = q_i + theta_offset_i`。

## 3. 坐标系定义

- `z_i` 为第 i 关节的转轴；URDF 中统一写成 `axis = 0 0 1`。
- `O_i` 位于第 i 关节轴与第 i+1 关节轴的公垂线交点。
- `x_i = z_i x z_(i+1)`，`y_i = z_i x x_i`。
- 对于关节 1/2，因两轴平行，frame 2 取 alpha=0、a=0.4105 m 的常用约定。

## 4. 夹爪移动关节

| 关节 | 父 -> 子 | CAD 导轨方向 | 范围 [m] |
|---|---|---|---|
| gripper_finger1_joint | link8 -> link9 | +Y | 0 ~ 0.015（夹紧） |
| gripper_finger2_joint | link8 -> link10 | -Y | 0 ~ 0.015（夹紧） |

两个关节均为 `prismatic`，局部 `axis = 0 0 1`；`q=0` 对应 CAD 装配位置。

## 5. 验证

- URDF 在 q=0 时的 visual/collision/inertial 与原始 CAD 最大位置误差：**4.6e-10 m / 1.1e-9 rad**。
- 64 组随机位姿下，新 URDF 正运动学与原始 CAD 装配位姿误差：**1.4e-9**。
- 10 个关节的局部 `axis` 均为 `(0, 0, 1)`。
- MJCF `robot.xml` 已通过 MuJoCo 编译；与 URDF 正运动学在 50 组随机位姿下最大误差：**4.2e-11 m / 2.6e-10 rad**。
