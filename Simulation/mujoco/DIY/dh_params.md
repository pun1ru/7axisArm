# 七轴臂 DH 参数表

由 `robot.xml`（q = 0 位形，世界系）测得，并与模型正运动学逐帧交叉验证。
长度单位 mm，角度单位 deg；关节变量 θ_i = q_i，**所有 θ 偏置为 0**。

几何前提：七根关节轴两两垂直且相交，因此

- 所有公垂线长度 a_i ≡ 0（表里 a 的小数只是轴线 1e-6 量级的不相交残差）；
- 相邻轴夹角恒为 90°，表里 α 全部为 +90°（源于 z 轴交替取 ±Y/±Z 的方向，见下）；
- 所有帧的 x 轴在世界系下同为 +X。

---

即 d = O_i − O_(i−1) 在 z_i 上的投影（见第 3 节的原点表）。

## 2. 标准 DH（Denavit–Hartenberg）

$${}^{i-1}T_i = R_z(\theta_i)\,D_z(d_i)\,D_x(a_i)\,R_x(\alpha_i)$$

| i | θ_i | d_i [mm] | a_i [mm] | α_i [deg] |
|---:|---|---:|---:|---:|
| 1 | q₁ | 62.600000 | 0 | +90 |
| 2 | q₂ | −4.000041 | 0 | +90 |
| 3 | q₃ | −147.999608 | 0 | +90 |
| 4 | q₄ | −2.499732 | 0 | +90 |
| 5 | q₅ | 99.998889 | 0 | +90 |
| 6 | q₆ | −0.999403 | 0 | +90 |
| 7 | q₇ | 0 | 0 | 0 |

两套表共用同一组原点 O_i 和同一组 d_i，只是 z 轴的归属错开一档：
改进 DH 里帧 i 的 z 是关节 i 的轴，标准 DH 里是关节 i+1 的轴。

构造规则：`O_i = J_i ∩ J_(i+1)`（关节 i 轴与关节 i+1 轴的交点，即 O_i 落在关节 i
轴线上、且 O_(i−1)→O_i 沿关节 i 轴线）；`z_i = J_i` 的方向；`x_i = z_i × z_(i+1)`。

把它挪到别的高度，d₁ 会跟着变，其余参数不动。

q = 0 时关节轴方向：z₁ = +Z, z₂ = −Y, z₃ = −Z, z₄ = +Y, z₅ = +Z, z₆ = −Y, z₇ = −Z。

## 5. 校验

- **参数分解残差**：每一对相邻帧按上表重构 `T_(i-1,i)`，平移残差 ≤ 2.4e-14 m。
- **正运动学**：用表链式算出的每一帧 vs `robot.xml` 逐 body 的真值，300 组随机
  关节角（各 ±3 rad），最大偏差 **2.6e-6 m / 2e-10（旋转矩阵元素）**。
  这点残差不是表写错了，而是模型自身轴线并不严格相交（Joint6–Joint7 间隙
  1.3e-6 m，Joint4–Joint5 0.48e-6 m）—— DH 参数化隐含"轴严格相交"，剩下的
  就是这个差。
- 关节限位：七轴均为 ±π rad，与 URDF 一致。

## 6. 与 `robot.xml` body 坐标系的关系（读数时注意）

DH 帧原点是 `O_i = J_i ∩ J_(i+1)`，也就是**关节 i 轴与下一根轴的交点**。当前
`robot.xml` 里 `link_i` 的原点被放在了前一个交点 `O_(i−1)` 上（沿关节 i 轴滑动了
一档，纯坐标系刻度，物理不变，`tools/check.sh` 仍 PASS）。两者沿关节 i 轴相差
一个 d_i：

| body | 到 DH 帧原点的距离 |
|---|---:|
| link1 | 62.600 mm |
| link2 | 4.000 mm |
| link3 | 148.000 mm |
| link4 | 2.500 mm |
| link5 | 100.000 mm |
| link6 | 1.000 mm |
| link7 | 0.001 mm |

源 URDF 的各个 `link_i` 原点原本就落在 `O_i` 上（与上表 DH 帧重合）。若要让 body
坐标系与 DH 帧一致，把这几个 body 沿各自关节轴平移 +d_i 即可。

另外说明：这个"帧 i 的原点在 J_i ∩ J_(i+1)"的结论与用哪种 DH 约定无关 ——
改进 DH 要求 `O_i − O_(i−1) ∥ z_i = J_i`，标准 DH 要求 `O_i − O_(i−1) ∥ z_(i−1) = J_i`，
两者都只有"相邻两个原点同落在关节 i 轴线上"才成立。若改用 `O_i = J_(i−1) ∩ J_i`，
分解残差恰好等于上表的 62.6 / 4.0 / 148.0 / 2.5 / 100.0 mm，即根本不存在满足
DH 形式的参数。

### 7.4 代价：四个竖直关节共线

理想版里 J1、J3、J5、J7 的轴线全部落在那条竖直线上（上表 x、y 恒定且都竖直）。
实测（tcp 处几何雅可比的奇异值）：

| 位形 | 真模型 | 理想版 |
|---|---|---|
| q = 0（全伸直） | rank 4，σmin = 0 | **rank 3**，σmin = 0 |
| 随机 30 组 q | 满秩，σmin 4.9e-3 | 满秩，σmin 4.5e-3 |
| q₂ = 0、其它任意 | 满秩但接近奇异，σmin 5.3e-6 | 满秩，σmin 3.1e-5 |

也就是说 4.0 / 2.5 / 1.0 mm 这三个偏置量级很小，但正是它们把 J1/J3、J3/J5、J5/J7
分开；理想版在全伸直位形上会再少一个自由度。除了这个位形，两者行为基本一致。
拿来做名义表、写论文、做控制器参数没问题；直接当仿真模型用，就别停在伸直位形。

## 8. 复现

在 `Simulation/Mujoco` 下用 `robot.xml` 的 q = 0 位形：取各关节轴（方向 + 过点）→
求相邻轴公垂线交点得 O_i → 由 `x_i = z_i × z_(i+1)` 组帧 → 对 `T_(i-1,i)` 按
第 1/2 节的形式分解。改模型后重跑此流程即可，d 列会随几何同步。
