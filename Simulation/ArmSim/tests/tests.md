# 数值逆解测试记录

> 2026-11-20 起，HOST_IK 数值解已改为“先预计算笛卡尔直线对应的完整关节轨迹，再执行”。
> 本文 2026-11-18 的在线逐步测试数据保留作历史对照，`max_lead_deg` 相关结论不再对应当前实现。

记录日期 2026-11-18。被测对象：HOST_IK 的数值解（`Algorithm/ik_numeric.{h,cpp}`、`Module/arm.cpp` 里的
`SetNumericIkTarget` / `StepNumericIk`），以及它和解析解的对比。

数值解的思路：每个 2 ms 控制周期在上一周期的关节目标处线性化，解一步
`Δq = J̄e + c·n`，其中 `J̄ = W⁻¹Jᵀ(JW⁻¹Jᵀ+λ²I)⁻¹` 是加权阻尼伪逆，`n` 是 J 的零空间向量，`c` 是 `k(q_ref − q)`
在 `n` 上的 W 加权投影。之后依次施加关节限位、每周期最大转角（默认 0.2°）和指令领先实测角上限（默认 5°）。
原理见 `Algorithm/ik_numeric.h` 顶部注释。

## 5. T4 实验 A：可达目标的覆盖率与精度

目标 = 随机关节角（在限位内均匀取）的正解，所以一定可达。三种求解：

- **解析解（当前分支）**：照搬固件 `SelectAutoPsi`：只用起点所在分支，ψ 每 2° 采样，要求肩腕非奇异（|sinθ| ≥ 0.02）、关节在限位内，取到起点位移平方和最小的解。
- **解析解（任意分支）**：同上，8 个分支都试。
- **数值解**：默认参数，最多 8000 周期（16 s），位置 ≤ 0.5 mm 且姿态 ≤ 2e-3 rad 算到位。

1500 个目标，起点 q=0（分支 5）：

| | 覆盖率 |
|---|---|
| 解析解，当前分支 | 78.1% |
| 解析解，任意分支 | 99.8% |
| 数值解 | 78.1% |

| 子集 | 个数 | 数值解到位 |
|---|---|---|
| 当前分支解析解可达 | 1172 | 1073（91.6%） |
| 仅其他分支解析解可达 | 325 | 96（29.5%） |

- 数值解到位而当前分支解析解到不了：99 个，其中 96 个最终分支和起点不同。反过来，当前分支解析解可达而数值解没到位也是 99 个。两者的工作范围有重叠但互不包含。
- 数值解到位的目标，最终分支与起点不同的有 684 个：数值解不受分支约束。
- 数值解没到位的 328 个，全部是卡在关节限位上的局部极小。其中 18 个残差已小于 5 mm 和 1°。没到位的残差：位置中位 0.018 m、最大 0.208 m，姿态中位 0.1°、最大 55.9°。
- 数值解到位的收敛周期：中位 834（1.67 s），p95 1456，最大 3027（6.05 s）。位置误差中位 0.1 mm，姿态误差最大 0.115°。
- 解析解是开环一步到位，位置误差中位 3.3e-8 m、最大 1.2e-7 m（float 精度）。
- 起点换成 q=[0,60,0,60,0,-30,0]（600 个）：当前分支解析解 70.7%，数值解 78.0%，趋势相同。
- 解析解的全部分支加 ψ 采样都找不到、但目标确实可达的有 1 个（ψ 网格 2° 可能漏掉很窄的可行区间）。

## 6. T5 实验 B：解析解到不了的目标

**B1 超出臂展。** 取随机构型的位姿，腕心沿肩到腕方向拉到 `Rmax + d`，姿态不变（`Rmax = √((d3+d5)²+d4²)`）。起点 q=0，每档 200 个：

| d | 解析解可达 | 末端位置误差 / d（中位，p90） | 腕心到肩距离 / Rmax（中位） | 完全伸直（> 0.99） | 比起点更近 | 不越限 |
|---|---|---|---|---|---|---|
| 2 cm | 0/200 | 1.00，4.40 | 1.000 | 142/200 | 200/200 | 200/200 |
| 5 cm | 0/200 | 1.00，1.95 | 1.000 | 150/200 | 200/200 | 200/200 |
| 10 cm | 0/200 | 1.00，1.76 | 1.000 | 145/200 | 200/200 | 200/200 |
| 20 cm | 0/200 | 1.00，1.37 | 1.000 | 142/200 | 200/200 | 200/200 |

中位数恰好是 1.00：数值解伸到边界，误差等于理论最小值 d。约 30% 的目标停在半途（p90 大于 1），原因是被限位卡住，没有逐个分析。

**B2 位置可达、姿态可能不可行。** 位置取自一个随机构型，姿态取自另一个，200 个：

- 解析解（任意分支）能到的 168 个里，数值解到位 134（79.8%）。
- 解析解到不了的 32 个，数值解 0 个到位。残差：位置中位 4.3 mm、p90 6.6 mm，姿态中位 27.4°、p90 44.1°，其中 18 个位置误差小于 5 mm。
- 姿态误差按 0.05 m 等效长度折算后参与最小二乘，所以位置优先于姿态。这是设计行为，不是缺陷。

## 8. T8 零空间实现对比

比较仓库里的「叉积精确投影」（`NullVector` 求 1 维零空间向量 n，投影 `c·n`）和「无阻尼加权伪逆投影」
`N = I − W⁻¹Jᵀ(JW⁻¹Jᵀ)⁻¹J`。后者由 `make_undamped_variant.py` 生成，只在 `tests/experiments/out/` 里，不进固件。

**cmp：600 个随机可达目标，起点 q=0**。两者完全相同：

| | 叉积（仓库） | 无阻尼变体 |
|---|---|---|
| 到位 | 472/600 | 472/600 |
| 靠近肩腕奇异的 65 个目标，到位 | 58 | 58 |
| 求解失败 | 0 | 0 |
| 收敛周期（中位 / p95） | 817 / 1429 | 817 / 1429 |
| 相邻周期 dq 突变（p99） | 0.333° | 0.333° |
| 运行时间 | 1.43 s | 0.90 s |

**proj：直接测零空间步的投影质量。** 任务误差设为 0，步长和限位放到极大（不被截断），零空间增益 1，
权重 {1, 2, 0.5, 3, 1, 1, 2}，参考构型很远，每种位形 300 组随机其余关节。两个量：

- 泄漏 `‖J·dq‖`（线速度部分），投影正确时应为 0。
- 放大 `‖dq‖_W / ‖z‖_W`，W 加权投影应 ≤ 1。

随机构型、肩奇异和近奇异（θ2 距 0 为 1°~0）、腕奇异和近奇异：两者相同，泄漏最大 4.8e-8 m（float32 精度），放大最大 0.92，没有超过 1 的。差别只在下面两处：

| 位形 | 叉积（仓库） | 无阻尼变体 |
|---|---|---|
| 肘接近伸直（θ4 = 180° − ε） | ε=0.1° 时 22/300 的 dq 被置 0；0.01° 时 123/300；0.001° 及精确伸直时 300/300 | dq 基本不为 0（精确伸直 1/300 为 0），泄漏最大 1.2e-8 m，放大最大 0.82 |
| 肩、腕同时奇异（秩 4，零空间 3 维） | dq=0（300/300），泄漏 0 | 泄漏最大 3.9e-8 m，放大最大 **1.285**，300 个里 1 个超过 1 |

`sing.cpp` 是第一次对比用的程序（目标 = 当前位姿，看一步之后的末端漂移），分辨力不够：
步长限幅 5° 会把异常量截掉，漂移又混入了步长二阶项，float32 的前向运动学也让"精确奇异"没有真正奇异。保留它只是为了记录，结论以 `proj.cpp` 为准。

结论：两种实现没有谁全面占优。叉积在肘伸直处会关掉零空间项（D4），无阻尼变体在肩腕同时奇异处有数值放大。
建议改成无阻尼变体并加一行保护（`‖dq_null‖_W > ‖z‖_W` 时按比例缩回），代码更少、更快。

**已实施。** 仓库的 `ik_numeric.cpp` 现在用无阻尼加权伪逆投影（删掉了 `Det6` 和 `NullVector`），并带上述保护。
实施后重跑：`ik_numeric_test` 的结果和改前逐项相同（441 周期收敛、随机目标 74/100 收敛、ALL PASSED）；
`proj` 在所有位形上放大都没有超过 1（肩腕同时奇异最大 0.891），肘接近伸直时 dq 不再被置 0（精确伸直 1/300），
泄漏最大 5.5e-8 m。`cmp` 没有重跑，上表「无阻尼变体」一列是改前的数据。

**D1 过程。** 实验 A 第一次跑，600 个可达目标只有 12.8% 收敛，远低于单个目标的结果。`diag.cpp` 对 300 个目标换参数重跑
（"停住" = 最后 50 周期最大关节增量 < 1e-3°）：

| 变体 | 修复前 到位 / 停住 | 修复后 到位 / 停住 |
|---|---|---|
| 默认参数，8000 周期 | 38 / 260 | 228 / 72 |
| 默认参数，40000 周期 | 38 / 262 | 228 / 72 |
| 阻尼 λ = 0.005 | 215 / 79 | 223 / 61 |
| 关掉零空间项 | 226 / 74 | 226 / 74 |
| 更大的误差和步长上限 | 38 / 256 | 233 / 63 |

周期加到 40000 结果不变、关掉零空间项就好，指向零空间项本身。原因：`J·J̄ = I − λ²A⁻¹`（`A = JW⁻¹Jᵀ+λ²I`），所以
`J(I − J̄J)z = λ²A⁻¹Jz ≠ 0`。起点离参考构型远时 `z` 大，这份泄漏和任务项的推力抵消，每周期末端净位移为零，关节就停住。
原来的单元测试起点离参考很近，`z` 小，泄漏可忽略，所以没发现。

修复：7 个关节全自由时零空间 1 维，用广义叉积 `n_i = (−1)^i det(J 去掉第 i 列)` 求 n，使 `J·n = 0` 严格成立，
再取 `c = nᵀWz / nᵀWn`。回归测试是 T1 的最后一项：100 个随机目标至少 65 个收敛（修复前约 13%，修复后 74）。

**D2。** `ik_numeric_test` 里"收敛"检查写成 `cycles < cap`，而没收敛时循环结束 `cycles` 也是 cap−1，所以永远为真。
这也让我第一次写的回归测试显示 100/100（实际没测出东西）。现在 `RunResult` 带 `converged` 字段，两处都改用它。

**D3。** 见 §7。逐关节钳位在各关节带宽差异大时不保持方向。可选的改法：整体等比缩放 Δq（保持路径）、
逐关节步长、对指令加加速度限制、把钳位状态上报上位机。目前都没做；只临时试过把 5° 放大到 60°，不是修复。

**D4。** 见 §8。

## 10. 没有覆盖的内容

- **实机。** 固件已有 C 端口（`ik_numeric.c`、`arm_ik.c`），PC 上用 MSVC 与 ArmSim 对拍结果完全相同，armclang 编译通过；
  但没有上板，没测过 STM32H723 上每周期的耗时，也没验证 ARM 的 `cosf` 与 MSVC 的 float 舍入差异。实机的 `TASK_ARM_PERIOD_MS` 是 2 ms，与仿真一致。
  固件侧的 `SET_IK_TARGET` 协议还没接，`Arm_SetNumericIkTarget` 目前没有调用方。
- **调坏的 PID。** 只有 D3 里 J6 本来就偏软的情形，没有系统地扫描增益。
- **固件非法 ik_method。** 回 `BAD_PARAM` 的分支没有走线测试，见 T3。
- **Host 面板。** 求解方式下拉框只有界面单元测试，没有人工点击过。
- **T7 样本量。** 11 个目标各跑一次，没有重复统计。
- **参数。** λ、k、max_step 等只在 T6 里试过 λ=0.005、k=0 和更大步长，没有系统调优。
- **非均匀权重。** 只在 T1 和 T8 的 `proj` 里测过，没有在仿真闭环里测。
