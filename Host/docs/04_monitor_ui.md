# 04 监视界面

> 对应 README 第 4 项。数据只从通信模块的回调 / 线程安全缓存获得，界面不直接碰串口。

## 启动

```bash
pip install -r requirements.txt          # pyserial, PySide6, pyqtgraph, numpy
python -m armhost.app --mock             # 直接连模拟设备演示
python -m armhost.app                    # 打开后在工具栏选数据源，再点"连接"
python -m armhost.app --port COM5        # 真实设备（Linux: --port /dev/ttyUSB0）
python -m armhost.app --replay logs/arm_20261030_013000.csv
```

## 数据流与线程

```
串口读线程 ──RobotSample──▶ MonitorController._on_sample
                              ├─ SampleBuffer.append   (numpy 环形缓存，加锁，30000 点 = 60 s @ 500 Hz)
                              ├─ latest = s            (加锁)
                              └─ CsvRecorder.put       (非阻塞入队 → csv-writer 线程写盘)
GUI 主线程：
  ScopeWidget  30 Hz  QTimer → buffer.view(window) → min/max 抽稀 → 已勾选曲线 setData
  JointTable / StatusPanel / 事件 / hex  10 Hz
  统计表  2 Hz（只在统计页可见时计算）
```

* 曲线对象在启动时一次建好（7 关节 × 5 量 = 35 条），之后只 `setData`，**不为数据点建 UI 对象**。
* 刷新与数据到达解耦：500 Hz 数据进来，界面仍是 30 Hz 批量刷新。
* 抽稀：所有勾选通道一起按屏幕宽度做 min/max 抽稀（一次 numpy 运算），单点尖峰不会丢；暂停后缩放会按新范围重新抽稀，放大到底能看到原始点。
* 实测（offscreen 软件渲染，最坏情况 35 条曲线 × 30000 点）：一次刷新约 28 ms；默认 21 条曲线、10 s 窗口时远低于此。

## 两种时间（README 要求明确区分）

| | 来源 | 用途 |
|---|---|---|
| **MCU 采样时间** `mcu_time_us` | 帧内时间戳，32 位回绕已展开 | 波形默认横轴；"MCU 采样频率""最大采样间隔" |
| **上位机接收时间** `host_time_ns` | 读线程收到该帧时的 `time.monotonic_ns()` | "接收频率""最长到达间隔""传输抖动" |

两台机器的时钟没同步，所以界面只给出 (接收 − 采样) 的**抖动**，不给"绝对延迟"。横轴可在两者间切换：USB/串口缓冲导致成批到达时，切到"上位机接收时间"会看到曲线呈台阶状，而 MCU 时间下是均匀的。

## 安全相关

* 工具栏"急停"（Ctrl+E）锁存急停；"解除急停"要二次确认。
* 切换数据源、断开、关窗口时，串口后端先发 ESTOP + CLEAR_TORQUE 再关线程。
* 本界面不提供直接力矩设置控件；Host 页只发送关节角度或 IK 位姿目标。

## 关节角闭环页

`Host 目标 → 关节角闭环` 用 7 组滑条 + 数值框直接编辑多圈关节角。载入当前角时按协议中的
`angle_deg` 原值填入，不再把多圈角截断到 `[-180°, 180°]`；滑条和数值框范围按固件单圈绝对
限位和当前实际圈换算成当前圈多圈区间。

拖动任意滑条会直接向对应关节发送闭环目标，不需要先进入模式或点发送按钮；其余
关节保持原目标和原闭环状态，适合逐轴调限位。点击“进入关节角闭环”会先载入当前角度，再把
7 个关节依次投入闭环；点击“重发全部 7 轴”可整体重新同步，点击“退出关节角闭环”或
“全部退出闭环”会清掉全部 Host 闭环。该操作只在 `HOST` 状态可用；进入 `HOST_IK` 后会由 IK
接管，关节角模式自动退出。

页面下方仍保留单关节调试按钮：一次只更新选中关节，可选择闭环或仅保存目标。固件限位只读，
Host 用读到的限位约束滑条范围，最终目标仍由固件再次按当前圈锁存限位校验。

## IK 闭环页

右侧 `Host 目标 → IK 闭环` 显示 `ARM_POSTURE` 上报的当前分支（λ2/λ4/λ6）和臂角 ψ。
只有设备处于 `HOST` 时才能点击“进入 IK 闭环”；进入后状态为 `HOST_IK`，7 个关节由 ArmSim
解析逆解结果闭环。首次收到有效构型会自动载入当前位姿和 ψ；`x/y/z`、`roll/pitch/yaw` 和 `ψ`
均使用滑条编辑。进入 `HOST_IK` 后拖动任意滑条会自动合并发送（约 50 ms 一帧，只保留一个
在途目标，结束后补发最新值），不需要再点发送；按钮只作为立即重发当前目标的备用入口。
ψ 滑条按圆周处理：拖到 `+180°` 后继续拖动会从 `-180°` 接着变化，反向同理。
再次点击按钮会退出 `HOST_IK` 并回到 `HOST`。IK 期间分支锁定，切换分支需先退出 IK。

“自动选择 ψ”打开后，固件在目标位姿、当前分支、关节限位和肩/腕非奇异条件下采样 ψ，并按
J0~J6 的多圈关节目标位移平方和选择代价最小的解；此时手动 ψ 滑条禁用，权重可在线调整并自动重发目标。
关闭后恢复手动 ψ。

目标区域顶部显示当前分支和当前滑条位姿下的 **ψ 可达区间**。Host 通过 `PARAM_READ`
读取设备实际 DH 与关节限位，本地复用同一套 S-R-S 解析解做预览，并排除肩奇异 `sinθ2≈0`、
腕奇异 `sinθ6≈0` 及约 1.15° 的近奇异余量；它只用于交互提示，不会替代固件的最终校验。
区间可能有多段，用 `∪` 连接。

## 兑换站页

`Host 目标 → 兑换站` 是 ArmSim 专用的紧凑控制页。一级到四级难度按规则表 5-10 生成
位姿；手动页可直接编辑 `x/y/z/θ/φ/α`。装配按钮严格按阶段启用：插入 100 mm、上移
100 mm、P 轴 +90°、Q 轴目标角、确认。自动演示会依次完成全部步骤，复位回到规则初始位姿。
状态区显示实际位姿、机构行程和随机种子；长内容放在滚动区，不扩大主窗口最小尺寸。
