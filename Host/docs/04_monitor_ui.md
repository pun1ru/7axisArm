# 04 监视界面

> 对应 README 第 4 项。数据只从通信模块的回调 / 线程安全缓存获得，界面不直接碰串口。

## 启动

```bash
pip install -r requirements.txt          # pyserial, PySide6, pyqtgraph, numpy
python -m armhost.app --mock             # 直接连模拟设备演示
python -m armhost.app                    # 打开后在工具栏选数据源，再点"连接"
python -m armhost.app --port COM5        # 真实设备（Linux: --port /dev/ttyUSB0）
python -m armhost.app --replay logs/arm_20261030_013000.csv
```

## 数据流与线程

```
串口读线程 ──RobotSample──▶ MonitorController._on_sample
                              ├─ SampleBuffer.append   (numpy 环形缓存，加锁，30000 点 = 60 s @ 500 Hz)
                              ├─ latest = s            (加锁)
                              └─ CsvRecorder.put       (非阻塞入队 → csv-writer 线程写盘)
GUI 主线程：
  ScopeWidget  30 Hz  QTimer → buffer.view(window) → min/max 抽稀 → 已勾选曲线 setData
  JointTable / StatusPanel / 事件 / hex  10 Hz
  统计表  2 Hz（只在统计页可见时计算）
```

* 曲线对象在启动时一次建好（7 关节 × 5 量 = 35 条），之后只 `setData`，**不为数据点建 UI 对象**。
* 刷新与数据到达解耦：500 Hz 数据进来，界面仍是 30 Hz 批量刷新。
* 抽稀：所有勾选通道一起按屏幕宽度做 min/max 抽稀（一次 numpy 运算），单点尖峰不会丢；暂停后缩放会按新范围重新抽稀，放大到底能看到原始点。
* 实测（offscreen 软件渲染，最坏情况 35 条曲线 × 30000 点）：一次刷新约 28 ms；默认 21 条曲线、10 s 窗口时远低于此。

## 两种时间（README 要求明确区分）

| | 来源 | 用途 |
|---|---|---|
| **MCU 采样时间** `mcu_time_us` | 帧内时间戳，32 位回绕已展开 | 波形默认横轴；"MCU 采样频率""最大采样间隔" |
| **上位机接收时间** `host_time_ns` | 读线程收到该帧时的 `time.monotonic_ns()` | "接收频率""最长到达间隔""传输抖动" |

两台机器的时钟没同步，所以界面只给出 (接收 − 采样) 的**抖动**，不给"绝对延迟"。横轴可在两者间切换：USB/串口缓冲导致成批到达时，切到"上位机接收时间"会看到曲线呈台阶状，而 MCU 时间下是均匀的。

## 功能对照

| README #4 要求 | 实现 |
|---|---|
| 1 显示角度、角速度、反馈力矩、设备状态 | 关节表 + 右侧"设备状态"（Arm 状态、遥控、急停/上位机力矩标志） |
| 2 多通道、变量选择、颜色、图例、缩放、平移、暂停恢复 | 通道网格（列头"全"整列切换，点关节按钮改颜色）；图例可开关；滚轮缩放、拖动平移；空格暂停 |
| 3 时间窗口滚动 | 2/5/10/20/30/60 s；拖动或缩放时自动暂停，"跟随最新"恢复 |
| 4 高频缓存、批量刷新、缓存上限 | 固定容量 numpy 环形缓存；30 Hz 批量刷新；状态栏显示占用 |
| 5 时间戳、接收频率、丢帧、串口状态 | 状态面板"时间""收发统计"两组 + 状态栏 |
| 6 CSV 记录、停止、回放、统计 | 记录/回放页（速度 0.25~5×、循环、暂停、拖动进度）；统计页（最小/最大/平均/标准差/RMS，范围 = 当前显示） |
| 7 不阻塞接收线程，不逐点建对象 | 见"数据流与线程" |
| 8 深色工程风格，跨平台 | Fusion + 调色板 + QSS，不依赖平台原生样式 |

## 安全相关

* 工具栏"急停"（Ctrl+E）锁存急停；"解除急停"要二次确认。
* 切换数据源、断开、关窗口时，串口后端先发 ESTOP + CLEAR_TORQUE 再关线程。
* 本界面**只监视**，不提供力矩设置控件。
