# 7axisArm
7axis control

## 一键启动仿真和上位机

```bash
./start_all.sh
```

默认会编译 ArmSim、把七轴臂和兑换站合并到普通 MuJoCo 地面、打开仿真窗口、创建
`/tmp/armsim-host` 伪串口并启动 Host。默认不再加载 2027 mjarena；需要其他场地时
可显式传入 `--arena <xml>`。

默认还会在机械臂前方加载可动的科技核心/兑换站。普通地面场景中，兑换站 O 点位于
地面 `z=0`；科技核心自身的 `z=0.5..0.7 m` 始终按规则相对 O 计算。机械臂基座坐标系
默认相对 OXYZ 为 `(200, 0, 300) mm`，即从 O 点沿 X 正向后退 200 mm、
高度 300 mm：

```bash
./start_all.sh --exchange-pose -200 200 800 0 90 0
./start_all.sh --arm-base-pose 200 0 300
./start_all.sh --no-exchange
```

无窗口运行：`./start_all.sh --no-viewer`。Host 参数放在 `--` 后传入，例如：

```bash
./start_all.sh -- --log DEBUG
```

Host 的中央区域新增 `MuJoCo 仿真` 页，内部包含：

- `关节角闭环`：7 轴角度滑条 + 数值框。拖动滑条会直接向对应关节发送闭环目标，不需要先进入模式；
  “进入关节角闭环”用于一次性锁存当前 7 轴并全部投入闭环。下方仍保留单关节调试按钮。
- `IK 闭环`：显示当前分支（λ2/λ4/λ6）和臂角 ψ；首次连接自动载入当前位姿，使用滑条编辑
  `x/y/z`、`roll/pitch/yaw`、`ψ` 后发送，并在目标区顶部显示当前位姿/分支下计算出的
  ψ 可达区间（同时满足关节限位和肩/腕非奇异条件）。修改位姿或参数后必须点击“发送目标”
  或“发送并计算”，不会自动下发；ψ 滑条可越过 `±180°` 循环拖动。点击“进入 IK 闭环”后 ArmSim 进入 `HOST_IK`，
  用 S-R-S 解析逆解把 7 轴闭环到目标；再次点击退回 `HOST`。页面同时显示实际 TCP 位姿，
  以及相对当前滑条目标的 `ΔXYZ`、总位置误差和姿态夹角误差。数值解先规划完整关节轨迹，
  计算期间机械臂保持不动；页面显示规划状态和本次计算耗时，完成后自动执行轨迹。
- `TCP / 工作空间`：当前固件 TCP 为 DH 末端沿 Z 轴偏移 `-0.045 m`，上位机切换 DH 时同步更新 TCP；
  三维工作空间
  同时区分浅蓝色“可达工作区”和橙色“灵活工作区”；后者要求同一位置覆盖至少 N 个 TCP 接近方向，
  N 可在面板调整。
- `兑换站`：选择一级到四级难度，按表 5-10 生成随机位姿或手动输入位姿；按规则顺序执行
  插入 100 mm、上移 100 mm、P 轴 +90°、Q 轴目标角和确认。也可一键自动演示。状态条显示
  实际 O→E 坐标、插入/上移量、P/Q 角和可复现随机种子。

右侧 `Host 关节控制` 只保留通用的关节角闭环，避免和 MuJoCo 专用控制混在一起。
