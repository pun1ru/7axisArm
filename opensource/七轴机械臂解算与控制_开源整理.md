## 1. 构型与建模

### 1.1 资料 A：3R-R-3R 七轴臂

- 关节 1、2、3 轴线交于肩心 S（球肩），关节 4 为肘，关节 5、6、7 轴线交于腕心 W（球腕）。
- 球肩/球腕条件：p12 = p23 = 0，p56 = p67 = 0。这使得解析逆解可以分解为“肩-肘-腕三角形 + 两个球关节”。
- POE 记法：H = [h1..h7] 为各关节单位轴，P = [p01, p12, ..., p67, p7T] 为相邻原点间固定向量。

MDH 参数（长度单位 mm）：

| J | θi | di | a(i-1) | α(i-1) | offset |
|---|---|---|---|---|---|
| 1 | q1 | L0 | 0 | 0 | 0 |
| 2 | q2 | 0 | 0 | π/2 | π/2 |
| 3 | q3 | L1 | 0 | -π/2 | 0 |
| 4 | q4 | 0 | 0 | π/2 | 0 |
| 5 | q5 | L2 | L1_3 | π/2 | 0 |
| 6 | q6 | 0 | 0 | -π/2 | 0 |
| 7 | q7 | 0 | 0 | π/2 | 0 |

数值：L0 = 0，d3 = L1_1 + L1_2 = 158.50，L1_3 = 60，L2_1 = 249.38，末端偏置 dEE = 92.57。
工具轴重映射：x_new = z_old，y_new = -y_old，z_new = x_old。

MATLAB Robotics Toolbox 建模写法（`Link('revolute','d',..,'a',..,'alpha',..,'offset',..,'modified')` 逐行建立，再 `SerialLink` 加 `tool`）见资料 A 第 3.2 节。

双臂安装：两基座相距 220 mm，左臂在 Y = -110，右臂在 Y = +110，末端朝世界 -X。

```
RWorldFromLeft  = [1 0 0; 0 0 -1; 0 1 0]
RWorldFromRight = [1 0 0; 0 0  1; 0 -1 0]
```

### 1.2 资料 B：Taurus 七轴臂

- 把 U 型小臂等效为虚拟连杆：Lv = sqrt(L2² + L3²)，φ = atan2(L2, L3)。
- 冗余自由度取 J3，作为外部给定参数。

### 1.3 资料 C：6-DOF 串联臂

- 关节顺序（末端到基座）：roll2、pitch3、roll1、pitch2、pitch1、yaw，满足 Pieper 准则，有解析解。
- 用于“过狗洞”场景，臂小，工作空间受限。

## 2. 逆运动学

四种思路，按适用场景选择。

| 方法 | 来源 | 冗余处理 | 适用 | 主要缺点 |
|---|---|---|---|---|
| 几何法（6-DOF） | C | 无冗余 | 6 轴 Pieper 构型 | 构型相关，需手推 |
| 固定 J3 的解析解 | B | 外部给定 J3 | 嵌入式实时，STM32H723 实测 91.78 µs | 需要外部搜索 J3 |
| SEW 臂角解析解（IK-Geo 子问题） | A | 臂角 ψ，沿一维流形优化 | 远距离目标 | 分支切换会破坏连续性 |
| 加权阻尼最小二乘（DLS） | A | 零空间/权重 | 连续小幅运动 | 局部方法，可能撞关节限位 |

调度：A 的 AdaptiveHybrid 按目标变化量选择求解器，见 2.5。

### 2.1 六自由度几何法（资料 C）

目标位姿矩阵第三列（末端 Z 轴单位矢量）记为 (cosZ'X, cosZ'Y, cosZ'Z)，腕点 P2 = p - L3 · z。

1. yaw：yaw = atan2(py - L3·zy, px - L3·zx)（原文取绝对值形式，见原 docx）。
2. pitch1、pitch2：P0P2 的模长与 L1、L2 构成三角形，用余弦定理求 θ2、θ4、θ5，再由直角三角形得 θ1，θ3 = θ1 + θ2。
3. pitch3：θ6 = arccos( (P2P3 · P1P2) / (|P2P3||P1P2|) )，其中 P1 = (-L1 cos yaw, L1 sin yaw, L1 sin θ3)。
4. roll1：延长 P1P2，求末端 P3 在其上的投影点 B；计算 roll1 = 0 时的末端点 D（Dz = P2z - L3 sin θ7，|P0D| 用余弦定理，Dx = |P0D'| cos yaw，Dy = |P0D'| sin yaw）。角度由 BD、BP3 的夹角给出，符号用叉乘第一个分量（基座 x 方向）判断。
5. roll2：令 roll2 = 0，用 MDH 求 R06，则 R = R06⁻¹ · Rref，roll2 = atan2(R21, R11)。

解算放在下位机（STM32H750）上，免去与上位机通信。

### 2.2 固定 J3 的七轴解析解（资料 B）

流程：先给定 J3，七轴降为六轴，再解析求解。

1. 腕部目标：T_base→wrist = T_world→base⁻¹ · T_world→target · T_end→tool⁻¹，取 Pwrist。
2. 虚拟肘角：由 Pwrist 到肩部的距离 d² = gx² + gy² + gz²，cos(q4_virtual) = (d² - L1² - Lv²) / (2 L1 Lv)，q4 = q4_virtual + φ。
3. 肩部两分支（q2 / q1）：
   - 局部坐标 X2 = Lv sin(q4v) cos(q3)，Y2 = Lv sin(q4v) sin(q3)，Z2 = L1 + Lv cos(q4v)。
   - 高度方程 gz = -X2 sin q2 + Z2 cos q2，令 R = sqrt(X2² + Z2²)，q2 = ±arccos(gz / R) - atan2(...)。
   - 水平半径 U = X2 cos q2 + Z2 sin q2，q1 = atan2(gy, gx) - atan2(Y2, U)。
4. 腕部三轴：R47 = (R04)ᵀ · R07，再从 R47 取 J5、J6、J7，sin(q6) 有两分支。sin(q6) 接近 0 时奇异，用上一帧 J5/J7 的分配关系保持连续。
5. 验证：FK → IK → FK_verify 闭环，位置和姿态误差约 1e-16。部署在 STM32H723，EventRecorder 实测均值 91.78 µs。

### 2.3 SEW 臂角解析解（资料 A）

用到 IK-Geo 的四个子问题：

| 子问题 | 形式 | 用途 |
|---|---|---|
| SP1 圆与点 | R(k,θ)p1 = p2，θ = atan2(aᵀp2, bᵀp2) | 球肩的 q3、球腕的 q7 |
| SP2 两圆相交 | R(k1,θ1)p1 = R(k2,θ2)p2，转为 SP4 | (θb, θc)，球肩 (q1,q2)，球腕 (q5,q6) |
| SP3 圆与球 | ‖R(k,θ)p1 - p2‖ = d，转为 SP4 | 肘角 q4 |
| SP4 圆与平面 | hᵀR(k,θ)p = d，a sinθ + b cosθ = c，θ = δ ± arccos(c/ρ) | 辅助角 θa |

SEW 臂角 ψ：肘部绕“肩→腕”轴 eSW 的旋转角。eCE = R(eSW, ψ) ex，参考方向 ex = fx(pSW) 决定零位和奇异集合。

求解步骤：

1. 指定 ψ，得到肘平面法向 nSEW 和 eCE = nSEW × eSW。
2. 肘角：‖R(h4,q4) p45 + p34‖ = ‖pSW‖，按 SP3 求 q4。
3. 肩部旋转 R03 = R(eSW,θa) R(nSEW,θb) R(eSW,θc)（辅助分解，非真实关节顺序）。
4. 用 SP2 求 (θb, θc)，用 SP4 求 θa（条件 nSEWᵀ R(eSW,θa) u = 0，u = R(nSEW,θb) R(eSW,θc) p34）。
5. 用半平面条件 eCEᵀ pSE > 0 筛选。
6. 球肩 R01R12R23 = R03 按 ZYZ 或 ZYX 分解，球腕 R45R56R67 = R47 分解。

分支：肘上/下、翻腕/不翻腕、翻肩/不翻肩，共 2×2×2 = 8 个候选。

奇异：
- 肩、肘、腕共线（pSW × pSE = 0）。
- 球肩奇异（q1 与 q3 不能分开确定）。
- 球腕奇异（q5 与 q7 共线）。
- 目标超出可达距离，无解。

参考方向的两种选法：

| 方式 | ex 的构造 | 奇异集合 |
|---|---|---|
| Conventional SEW | 将固定参考向量 er 投影到垂直于 eSW 的平面并归一化 | eSW = ±er，一整条双向直线 |
| Stereographic SEW | 经极点 et、当前球面点的平面与单位球交线的切向 | 仅 eSW = et，单向 |

臂角一维流形优化：固定末端位姿时解为 q(ψ)，代价 E(ψ) = Σ wi (qi(ψ) - qi,c)²。

- 以当前 ψ0 为中心，δψ = 0.01 rad，取三点 E-、E0、E+。
- 中心差分：g ≈ (E+ - E-)/(2δψ)，h ≈ (E+ - 2E0 + E-)/δψ²。
- h > 1e-5 时，Δψ = clamp(-g/h, -0.1, 0.1)，否则 Δψ = clamp(-0.05 g, -0.05, 0.05)。
- ψ0 不可行时，搜索 ±5°、±10°、±20°、±40°，取代价最小的可行点。
- 最坏情况闭式求解 3 + 8 + 2 + 1 = 14 次。以上阈值为经验参数。

### 2.4 数值逆解：加权 DLS（资料 A）

- 末端误差：位置 ep（mm），姿态 eR = ½ Σ ra,k × rd,k ≈ δφ。
- 量纲统一：取等效长度 LR = 0.1 m，ee = [1e-3·ep; LR·eR]，Je = [1e-3·Jv; LR·Jω]。
- 几何 Jacobian 第 i 列：Ji = [ai × (pT - oi); ai]，ai = R(i-1) Hi。J ∈ R^(6×7)。
- 最小范数解：Δq = J†e，通解加零空间项 (I - J†J) z。
- DLS：min ‖JΔq - e‖² + λ²‖Δq‖²，奇异方向增益 σ/(σ²+λ²)。
- 加权形式：min ‖JΔq - e‖² + λ² ΔqᵀWqΔq，代码使用对偶形式 Δq = Wq⁻¹Jᵀ (J Wq⁻¹ Jᵀ + λ²I6)⁻¹ e。

### 2.5 AdaptiveHybrid 调度（资料 A）

| 方法 | 优势 | 局限 |
|---|---|---|
| 加权 DLS | 从真实反馈出发，连续性好；阻尼和权重便于约束肩部 | 依赖线性化，受迭代次数和信赖域限制 |
| Hybrid（SEW 粗遍历 + 一维流形投影） | 远目标可达性强 | 解析分支切换可能使小目标换支 |

规则：Δp = ‖pd - pc‖，Δθ = arccos(clamp((tr(RcᵀRd) - 1)/2, -1, 1))。Δp ≤ τp 且 Δθ ≤ τR 时用 DLS，否则用 Hybrid。阈值 τp、τR 报告里没给数值。

已知局限：沿笛卡尔闭曲线持续运动时，DLS 可能让某关节单向增长并卡在限位；中远距离 point-to-point 的严格连续轨迹规划尚未实现。

## 3. 重力补偿

三种推导路线，结论等价，实现难度不同。

### 3.1 雅可比法（资料 C，平面臂）

- 虚功原理：τ = Jᵀ F，重力补偿 τ = -Jmᵀ G，Jm 为连杆质心处的雅可比。
- 各连杆质心位置：
  - p1 = (l1m s1, l1m c1)
  - p2 = (l1 s1 + l2m s12, l1 c1 + l2m c12)
  - p3 含 pitch3 与 roll1 的投影角 θ5 = arcsin(s3 c4)
- 总力矩 τ = τ1 + τ2 + τ3，只补偿 pitch1/2/3 与 roll1；yaw 与 roll2 不需要。
- roll1：τroll1 = -m3 g l3m s3 s4 s12。

### 3.2 力臂叉乘 + 轴投影（资料 B，最容易上板）

```
r_i,k = P_com_k - P_joint_i
g_k   = m_k * g_vec
τ_vec_i,k = r_i,k × g_k
τ_i = Σ_{k=i..n} ( τ_vec_i,k · Z_i )
```

- P_joint_i 取 T_0_to_i 的平移列，Z_i 取旋转矩阵第三列，局部质心经 link 变换到世界系。
- 必须把空间力矩点乘到关节轴 Z_i 上，不能直接取世界 z 分量。
- 关节 i 要承担其后所有连杆、夹爪和抓取物，所以从 k = i 累加到末端。
- 夹持矿石等额外质量：加一项 (P_load - P_joint_i) × (m_load g) · Z_i，或并入末端 link。
- 计算量只有向量叉乘/点乘，可以放在 STM32 控制周期里。
- 实车效果：赛后用重力补偿摆出比心姿势，自定义控制器上可完全静止。

### 3.3 势能梯度法（资料 A，含左右臂与腰部俯仰）

静力学：τcmd = τctrl + τ̂g(q)。势能 P = Σ mi g uᵀ pi(q)，τ̂g = ∂P/∂q。

三段等效质量 mU、mF、mT 合并成“质量乘质心”向量：

```
A = mU cU + (mF + mT) p34      对应 R03
B = mF cF + mT p45             对应 R04
C = mT cT                      对应 R07
S(q) = R03 A + R04 B + R07 C
```

旋转链：R03 = Rz(q1) Ry(-q2) Rx(-q3)，R04 = R03 Ry(-q4)，R07 = R04 Rx(q5) Ry(-q6) Rx(q7)。

按所给几何（p34 = [-L1,0,0]ᵀ，p45 = [L2,0,Le]ᵀ，p7T = [LT,0,0]ᵀ）：

- A = [-(λU mU + mF + mT) L1, 0, 0]ᵀ
- B = [(λF mF + mT) L2, 0, (λF mF + mT) Le]ᵀ
- C = [λT mT LT, 0, 0]ᵀ

关节力矩（需要辨识的量是 A、B、C 共 9 个分量，加每关节常值偏置 bi）：

```
τ̂g,i = g ( ux ∂Hx/∂qi + uy ∂Hy/∂qi + uz ∂Hz/∂qi ) + bi,   (Hx,Hy,Hz) = S(q)
```

重力方向 u = R_Mᵀ R_WMᵀ e_z,w：

| 场景 | 重力在本地系的方向 |
|---|---|
| 固定安装，左臂 | u = [0, +1, 0]ᵀ |
| 固定安装，右臂 | u = [0, -1, 0]ᵀ（符号相反，不能复用左臂符号） |
| 腰部有俯仰 ψ | uL = R_MLᵀ uM，uR = R_MRᵀ uM，uM = R_WMᵀ e_z,w |

腰部俯仰电机自身：τψ = ∂/∂ψ [ g uL(ψ)ᵀ SL(qL) + g uR(ψ)ᵀ SR(qR) + Pbody(ψ) ]。报告说明该项仍需按此式单独计算，未实现。

验证：MuJoCo 中按当前关节状态实时计算预测值，并用独立脚本交叉检查。

## 4. 关节空间柔顺控制（资料 B）

目标：既能拖动柔顺，又能跟随目标，同时不让电机过热。

- 纯位置 PID：跟踪强，但拖动僵硬。
- 纯重力补偿：无目标约束，定位精度差。
- 小增益 PD + 重力补偿：仍受减速机、轴承的静/动摩擦和回差影响，跟随不够准。
- 外置力矩传感器 + 摩擦观测器：理论可行，但当前平台没有传感器，且模型误差大时可能引入异常力矩。

采用方案：重力前馈 + 关节空间 PD + 仅对 PD 输出限幅。

```
tau_pid_raw = Kp (q_ref - q_fdb) + Kd (dq_ref - dq_fdb)
tau_pid     = sat_pid(tau_pid_raw)
tau_cmd     = tau_g + tau_pid
```

- 重力项 tau_g 不经过限幅，在限幅之后叠加。
- q_ref 来自 arm_task，q_fdb / dq_fdb 来自电机编码器。
- 实测：分区赛多局连续对抗和操作手长时间训练中，臂部电机未出现过热失能，无需额外冷却。

## 5. 软件架构（资料 A）

四层结构：

| 层 | 职责 |
|---|---|
| Router | 解析 DR16 输入（键鼠、拨杆、摇杆），生成 RouterOutput 操作请求 |
| FSM / Actions | 判断当前允许的动作，生成 MotionTarget |
| RoboArmT + ArmMiddleware | 安全约束、运动学、空间映射、轨迹规划、重力补偿 |
| ArmDriver | 电机使能、反馈有效性、在线检查、达妙 MIT 协议下发 |

要点：

- 左右臂共用同一套模板 RoboArmT，左臂 CAN1，右臂 CAN2，每臂 7 个达妙电机 J0–J6。
- 每个周期顺序：`getFeedback()` → `calculateOutput()` → `setSendOutput()`。
- 全部关节使用 NativeMIT；CustomMIT（软件侧 PD、力矩前馈、限幅）预留未启用。
- 目标更新路径：限幅 → 禁区检查 → IK → 关节限位 → 空间映射（关节↔电机）→ 电机空间轨迹。新旧目标等价时沿用已有轨迹。
- 周期路径：同步参考系 → 更新参考偏移 → motor→joint → FK → 刷新参考 → 重力补偿与速度规划 → 输出。
- 参考系（腰部俯仰 IMU）变化超阈值且满足最小重规划间隔才重规划，避免 IMU 噪声频繁触发。
- 初始化：要求连续 50 帧有效 Pitch/IMU，七个电机反馈在有效时限内，再用实测反馈初始化中间层。
- 多层保护：参考系稳定性 → 反馈有效性 → 笛卡尔约束 → 禁区 → IK → 关节限位 → 电机在线。
- 虚拟弹簧 VirtualSpring：用力矩残差和速度反馈做堵转检测，只输出 StallFlag，不参与控制。
- Router 使用注意：`dispatchRouteMap()` 不会清空输出，调用者每周期先 `output.reset()`。

已知局限（报告自述）：

- 位姿增量按调用次数累加，没有时间基准，速度随调用周期变化。
- NativeMIT 未用 torqueMax 对前馈限幅。
- 软/硬复位是经验分段路径，不是碰撞规划。
- 各层以裸指针传递对象，生命周期靠上层保证。

## 6. 任务级应用（资料 C，自动兑矿）

1. 识别：RealSense D435i 采图，OpenCV 二值化、轮廓筛选、三角形拟合，取三个顶点二维坐标，结合深度转三维，得到物体位姿 Tco，串口发送。
2. 坐标系：相机装在 pitch2 上，Tbc 由 DH 求得，兑换槽位姿 Tbo = Tco · Tbc（原文写法）。物体系 Z 轴取兑换槽入口方向，与末端系保持一致，避免下位机多一次旋转。
3. 运动规划三步：
   - 底盘补偿：chassis_x = Xo - Xc，chassis_y = Yo - Yc，其中 Yc = 0 + 200·Zy，让左右两侧工作空间都能用上。
   - 中间点：p = (Xc - 300Zx, Yc - 300Zy, Zc - 300Zz)，矿石长 200 mm，留余量。
   - 推入：沿 Z 轴按步长累加 p = p + Z·Δt，总位移 300 mm。
4. 遇到的问题：
   - 深度相机低信噪比，深度跳变；均值、中值、滑动窗口均未根治，直线推入时蹭槽边。
   - 中间点超出臂工作空间，逆解无有效解。文中提到上海交通大学的“绕某棱旋转推入”方案可参考。

## 7. 设计阶段：用 MATLAB 选杆长（资料 B，六自由度阶段）

把杆长选型变成可统计的指标，在结构定型前筛掉不可行方案。

- 任务拆成 Transl、P_Rotate、Q_Rotate 三阶段，逐帧判可达。
- 任务集合 Tasks = ndgrid(X, Y, Z, TH, PH, AL)；候选杆长 Configs = ndgrid(L1_Range, L2_Range)；基座候选 Bases = Base_Y_List。
- 简化：E 系 y 不必遍历；x、z、phi、alpha 各取起点/中点/终点；theta 取 (-90,0) 和 (0,90) 利用对称；基座 z 取 0.35 m，x 贴场地道具取 0.2 m。
- 三个指标：

```
coverage_rate           = N_reachable / N_task
avg_adaptability        = Σ single_task_adaptability / N_reachable
perfect_ratio           = N_perfect / N_task
```

  覆盖率回答“能不能做”，灵活性回答“停车位置偏一点还能不能做”，满分率回答“哪些任务点在所有基座位置下都稳”。
- 相关脚本名：`get_robot_description.m`、`get_target_description.m`、`calculate_scene_trajectory.m`、`my_Inverse_solution.m`、`run_arm_optimization.m`。
- 结果：电控角度最优 L1 = 0.40 m，L2 = 0.46 m；最终杆长还要结合机械尺寸限制。

## 9. 选型建议

| 需求 | 建议 |
|---|---|
| 6 轴、满足 Pieper、算力有限 | 资料 C 几何法，或直接解析 |
| 7 轴、嵌入式实时、可接受外部搜索冗余角 | 资料 B 固定 J3，91.78 µs |
| 7 轴、需要臂角连续、目标可能较远 | 资料 A：连续小动作 DLS，远目标 Hybrid（SEW） |
| 重力补偿快速上板 | 资料 B 叉乘+轴投影，复用 FK 的 T_0_to_i |
| 重力补偿需要含基座俯仰/左右臂 | 资料 A 势能梯度，辨识 A、B、C 三个向量 |
| 要拖动柔顺同时防过热 | 资料 B 重力前馈 + PD + PD 输出限幅 |
| 要 6D 笛卡尔空间阻抗 | 看 opensource.md 里 Panthera-HT-ROS2（未核实） |
| 要做质量/质心辨识 | 看 gravity_identification（未核实）；资料 A 的 A、B、C 即待辨识量 |
